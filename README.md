# آستان جانان

اپلیکیشن اندرویدی فارسی با Kotlin و Jetpack Compose.

## شروع سریع
- راهنمای فارسی: `README_FA.md`
- ساخت APK خودکار: زبانه **Actions** در GitHub و اجرای workflow با نام **Build Astane Janan APK**
- خروجی ساخت: فایل Artifact با نام `Astane-Janan-Android-0.2.0`

این نسخه آزمایشی است. APK فقط پس از اجرای موفق GitHub Actions ساخته می‌شود. بخش‌هایی مانند قرآن کامل، محاسبه واقعی اوقات شرعی، قبله‌نما و نجوم هنوز در حال توسعه‌اند.
