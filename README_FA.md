# آستان جانان — Android 0.2.0

اپلیکیشن Native Android با Kotlin و Jetpack Compose؛ طراحی RTL با تم سرمه‌ای و طلایی.

## تغییرات نسخه 0.2.0
- تبدیل صفحه ذکر به دفترچه چندذکری؛ امکان تعریف تعداد نامحدود ذکر.
- ایجاد، ویرایش و نگهداری نام، توضیحات و تعداد هدف هر ذکر.
- شمارنده مستقل برای هر ذکر و ذخیره خودکار اطلاعات روی دستگاه با SharedPreferences.
- اعلان سیستم هنگام رسیدن شمارنده به تعداد هدف، با امکان فعال/غیرفعال کردن برای هر ذکر.
- ثبت تاریخ و ساعت هر بار تکمیل تعداد هدف و نمایش تاریخچه اختصاصی هر ذکر.
- آرشیو و بازیابی ذکرها؛ داده‌های هر ذکر و سوابقش همراه آن باقی می‌ماند.
- افزودن GitHub Actions برای ساخت خودکار APK بدون نیاز به Android Studio روی رایانه کاربر.

## ساخت APK از طریق GitHub Actions
1. کل محتویات این پوشه را در ریشه یک مخزن GitHub قرار دهید؛ فایل workflow باید دقیقاً در مسیر `.github/workflows/android-apk.yml` باشد.
2. تغییرات را روی شاخه `main` یا `master` پوش کنید.
3. در مخزن GitHub وارد زبانه **Actions** شوید و اجرای **Build Astane Janan APK** را باز کنید.
4. پس از سبز شدن مرحله Build، در پایین صفحه اجرای Workflow، بخش **Artifacts** را باز کنید.
5. فایل `Astane-Janan-Android-0.2.0.zip` را دانلود و از حالت فشرده خارج کنید؛ فایل داخل آن `app-debug.apk` است.
6. APK را به گوشی منتقل و نصب کنید. برای اعلان‌های اتمام ذکر، اجازه Notifications را به برنامه بدهید.

همچنین می‌توانید از زبانه Actions گزینه **Run workflow** را برای ساخت دستی اجرا کنید. با ساخت Tag مانند `v0.2.0`، APK علاوه بر Artifact به Release همان Tag نیز پیوست می‌شود.

## فناوری و نسخه‌ها
- Kotlin 2.0.21
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- Java 17
- compileSdk 35 / targetSdk 35 / minSdk 26
- Application ID: `com.astanjanan.app`

## وضعیت و محدودیت‌های فعلی
- داده‌های ذکر در حافظه داخلی برنامه ذخیره می‌شوند و برای کارکرد دفترچه ذکر اینترنت یا حساب کاربری لازم نیست.
- تاریخچه فعلی، هر بار رسیدن به تعداد هدف را با تاریخ و ساعت ثبت می‌کند؛ صفر کردن شمارنده تاریخچه قبلی را حذف نمی‌کند.
- اعلان پایان، اعلان فوری سیستم هنگام رسیدن به هدف است؛ آلارم زمان‌بندی‌شده در ساعت مشخص هنوز پیاده‌سازی نشده است.
- قرآن کامل، موتور واقعی اوقات شرعی، قبله‌نما، نجوم و تقویم در این نسخه هنوز ماژول‌های اولیه هستند.
- Workflow در GitHub اجرا می‌شود و APK را به‌صورت Artifact تحویل می‌دهد؛ این محیط فعلی Android SDK ندارد، بنابراین APK در اینجا کامپایل یا تست نشده است. اولین اجرای GitHub Actions باید موفق شود تا فایل نصب‌پذیر ساخته شود.
